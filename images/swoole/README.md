# swoole — production base (not built yet)

A placeholder for a production base image for Laravel Octane on Swoole. Nothing
here yet: no project uses Octane so far.

The starting point when one does: base on `php:<version>-cli`,
`install-php-extensions swoole` and the same set of extensions as the FrankenPHP
base.

For the procedure, see [CONTRIBUTING.md](../../CONTRIBUTING.md#adding-a-new-image).
